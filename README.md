# 메디넷 부동산 블로그 스튜디오 (블로그3)

주제와 **내 경험 메모**를 넣으면 Claude(claude-opus-5-5)가 `블로그포스팅 프롬프트.txt` 기준으로
네이버 블로그 글을 쓰고, **글 내용에 맞는 이미지**(대표·단계·비교표·그래프·체크리스트 등)를
메디넷 부동산 로고를 넣어 자동으로 그려 주는 내 PC용 대시보드입니다.
매물 광고 텍스트를 `부동산 매물정리 프롬프트.txt` 기준의 표로 정리하는 기능도 들어 있습니다.

## 내 PC에서 실행하기

1. [Node.js](https://nodejs.org) 설치 (LTS 버전)
2. `start.bat` 더블클릭 → 브라우저에 `http://localhost:3300` 이 열립니다
3. 왼쪽 **설정**에 Anthropic API 키(`sk-ant-...`)와 사무소 정보를 넣고 저장
   - 또는 `.env.example` 을 `.env` 로 복사해 키를 적어 두면 매번 넣지 않아도 됩니다

> 구글 드라이브 폴더 안에서는 `npm install` 이 깨지므로 `start.bat` 은 파일을
> `%LOCALAPPDATA%\medinet-blog-studio` 로 복사해서 실행합니다. 코드를 고쳤다면 `start.bat` 을 다시 실행하세요.
> 단, **프롬프트 .txt 파일은 이 폴더(`prompts`)의 원본을 바로 읽으므로** 고치면 다음 글부터 바로 반영됩니다.

## 사용 순서 (제목만 넣으면 끝)

1. **블로그 글쓰기**에 제목(주제)만 넣고 *자동으로 완성하기* (2~4분) — 글·이미지·사진·태그가 빈칸 없이 완성됩니다
2. **네이버 글쓰기 열기** → 오른쪽 위 **① 제목 복사** → 제목 칸에 붙여넣기
3. **② 본문+이미지 붙여넣기** → 오른쪽 아래 도우미가 글·이미지를 한 조각씩 복사합니다. 네이버 본문 맨 끝을 클릭하고 Ctrl+V → 도우미의 *다음* → Ctrl+V … 를 끝까지 반복 (이미지가 정확한 자리에 들어갑니다)
4. **③ 태그 복사** → 태그 칸에 붙여넣기 → 발행
   - 네이버 편집기는 글 속에 섞인 이미지를 버리기 때문에, 이미지를 한 장씩 따로 복사하는 방식을 씁니다. 두 창을 나란히 띄우면 빠릅니다
   - 사진이 마음에 안 들면 그 이미지 아래 *다른 사진*을 누르면 다른 사진으로 바뀝니다

> 네이버는 블로그 글 자동 발행 API를 제공하지 않고, 프로그램이 대신 로그인해 발행하면 계정 제재 위험이 있어
> 마지막 붙여넣기·발행만 직접 하도록 만들었습니다.

**매물 정리** 화면에서 매물 텍스트를 표로 정리한 뒤 *블로그 글에 넣기*를 누르면, 그 매물 사실만 사용해 글을 씁니다.

## 이미지는 어떻게 만들어지나요?

Claude가 글을 쓰면서 이미지 자리마다 "어떤 그림이 들어가야 하는지"(종류·제목·항목·수치)를 함께 설계하고,
화면이 그 설계대로 1200×800 이미지를 그립니다. 사진 자리와 대표 이미지 배경에는 상업적 이용·수정이 허용된 무료 사진(Openverse의 CC 라이선스 사진, 설정에 Pexels 키를 넣으면 Pexels 고화질 사진)을 자동으로 찾아 넣고, 이미지 아래에 사진 출처를 표시합니다.

| 종류 | 언제 쓰나 |
|---|---|
| 대표(cover) | 글 맨 앞 썸네일 |
| 단계(steps) | 절차·순서 |
| 비교표(compare) | 대안 비교 |
| 그래프(bar)·핵심 수치(stats) | 출처가 확인된 숫자 |
| 체크리스트·핵심 요약(tip) | 정리용 |
| 사진(photo) | 상업적 이용·수정이 허용된 무료 사진을 자동으로 찾아 로고를 넣음 |

## 글 품질 장치

- 경험 메모가 없으면 공인중개사 실무 지식과 현장에서 흔한 상황·수치 예시로 채워 빈칸 없이 완성합니다. 특정 손님·거래를 실제 있었던 일처럼 지어내지는 않습니다. (내 경험 메모를 넣으면 더 좋은 글이 됩니다)
- *최신 자료 웹 검색*으로 통계·제도를 실제 출처로 확인하고, 인용한 출처 목록을 글 아래에 보여 줍니다.
- 프롬프트 10·11번 기준으로 스스로 점검·보완한 결과를 보여 줍니다.

## 파일 구성

|---|---|

| `public/images.js` | 내용 맞춤 이미지 그리기 (로고·사무소 정보 포함) |
| `public/logo.png` | 메디넷 부동산 로고 |
| `public/demo.js` | '예시로 미리보기' 샘플 |
